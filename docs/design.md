# 憧れの残響 — 设计决策与分镜文档

本文档整理 Kara 与 Claude 设计对话中确定的内容，随每次设计推进更新。
创意设计由 Kara 全程主导；Claude 负责工程实现与备选方案。

## 0. 总则（已锁定）

- 定位：**Web 静止系 MAD** —— 以歌曲播放为时间轴的 4:29 实时演出，每句歌词一卡。
- 布局：**全屏沉浸**（非固定画幅）；移动端强制横屏（竖屏遮罩引导）。
- 交互原则：**3D 内容可操控**（用户可拖拽旋转观测角度、旋转对象）；
  **2D 内容不可操控**（文字演出、图片演出不响应指针）。
- 页面 UI 主体英文；标题轮播为 日 / 英 / 中 / 韩 四语。
- 音频：直接播放站内打包音源（无本地文件选择）；`?silent=1` 静默排演供开发。
- 歌词文本以 `src/data/lyrics.js` 为准（BA TW 官译 + Kara 英段中译），纠错后置。

## 1. 开场页（已实现，`src/opening/`）

1. 「憧れの残響」于页面中部略下方由下往上淡入（BA 剧情标题式），停留 1s
2. 正中射出一小段竖线（22vh），双边内容如**抽屉**自线段后拉出（被中线裁切）：
   左＝封面 + 标题移至封面正上方（贴合、整体上下对称），右＝Staff 与上一级按钮；
   双边同始同终；标题随后以日/英/中/韩轮播
3. 线段消失 → Malkuth 光环**中心点**浮现 → 双边继续靠边让位
4. 光环轮廓自顶部**顺时针加速**发光显现（3D：edge-on 姿态逆时针倾斜 30°，
   22 棱面，形态参考 Malkuth_Halo.png：对称正圆 + 中心一点）
5. 下方浮现 Tap Halo to Continue，光环即入口
6. 点击：内容区自右下向左上**粉末消散**（符合物理学；光环除外——按入场逆序退场）
7. 进入播放器；**开场 → 播放器的过渡演出待定**

参数集中在 `opening.js` 顶部 `T`/`POS`，光环常量在 `malkuthHalo.js` 顶部。
移动端：竖屏进入等转横屏再开演；点击前方向翻转/视口大幅变化则整场重排重演
（地址栏收起类的小幅变化不触发）。

小屏与层级约定（2026-07-06 修订）：光环半径 2.05、管径保持细；**内容区覆盖在
光环之上**（DOM 高于 WebGL 画布），小屏允许双边内容与光环重叠；抽屉裁切仅在
拉出动画期间生效，完成后撤下；靠边距离按内容宽度收敛，不把内容推出屏幕；
线段生长的同时标题即开始让位（不被线段劈开）；窄屏（≤780px）右列限宽换行。

## 2. 前奏 0:00–22.5「钢铁殿堂」（已实现，`src/cuts/intro/`）

参考：ED MV 开头（钢铁大陆殿堂的多层破碎光环）。

- 舞台：开场过渡结束后，**殿堂自暗场淡入**（0–2.5s）；背景渐变为晴空——
  **上蓝下白的垂直渐变**（0–4s 淡入，`fx/sky.js`）。
- 殿堂（`fx/sanctum.js`）：程序化多层同心钢铁光环，**「由好到坏」的崩解演出**——
  初始致密完整（仅 6% 原生缺口），每块拥有自己的崩解时刻（3–22s，后段加速），
  到点后外抛/坠落/翻滚并在数秒内收缩消散，前奏结束时殿堂明显分崩离析；
  **金色光环初始为完整一圈**（贴外环上缘的光带，Bloom 发光），2–16s 间逐块
  碎散上浮，前奏后段完全消失。固定随机种子 + 状态为 t 的纯函数，seek 安全。
- 相机（`cuts/intro/sanctum.js` 顶部 `CAM` 可调）：
  - 0–11s 近景仰视，置身环带之间（MV 图一）；构图右移 16%——殿堂落在
    2/3 线上（中+右侧），左 1/3 留给 Staff 字幕（ED 式三分构图）
  - 11–14.5s 拉远过渡（俯仰柔性引导，构图回正居中）
  - 14.5–22.5s 殿堂光环全景（MV 图三）
  - 全程可拖拽旋转（OrbitControls；禁缩放/平移；距离与注视点由演出接管）
- 天空下半球压暗为雾蓝（`fx/sky.js` uDown），俯视不刺眼。
- Staff 字幕（`cuts/intro/credits.js`）：屏幕左侧，淡蓝描边 + 白色内芯，
  三批淡入淡出（时机 Claude 定，顺序 Kara 定）：
  1. 1.5–10.6s：Music / Mitsukiyo ・ Lyrics / Yuno Yoshimi (IOSYS) ・ Vocal / DAZBEE
  2. 11.2–17.1s：Translation / Blue Archive, Kara251 ・ Ending Song / Blue Archive Ex. Decagrammaton ED
  3. 17.7–22.0s：Website Visual Design / Kara251, lyrics.kara251.com
- 21–22.4s 殿堂与天空整体淡出，交棒主歌一。
